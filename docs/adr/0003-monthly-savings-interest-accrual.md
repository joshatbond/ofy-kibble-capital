# Monthly savings APY on all savings balances (including vaults)

PawKet Change teaches that money in savings grows. **Savings APY** is set per classroom by the teacher (default **3.3%**). **Interest accrual** runs on the **1st of each calendar month** (same family of scheduled jobs as payday automation), crediting interest on **all** savings balances—unallocated savings **and** vault balances—like real life, not checking.

**Considered options:** No interest in v1 (rejected — misses learning goal); interest on unallocated savings only (rejected — vaults are part of savings in SoFi-style model); daily accrual (rejected — unnecessary precision for simulation).

**Consequences:** Ledger must post interest as its own line type; students see vault goals grow without manual deposits. APY changes apply going forward; backdating needs explicit policy if teachers edit mid-year. Interest amount uses **average daily balance** over the prior calendar month (see glossary).
